# 用户管理前端

用户管理页面位于 `/users`，使用现有后端接口。

## 页面行为

- 用户列表只显示用户名，移除额外显示名称与备注标记；新增和编辑抽屉均不提供显示名称输入，编辑抽屉移除备注及第三方绑定身份信息。
- 新建用户仍将用户名作为兼容接口所需的显示名称。编辑已有用户时，内部保留加载到的原显示名称、备注，不因隐藏字段而清空原数据；第三方绑定关系不变。
- 用户资料加载完成前，禁止保存和编辑额度，避免使用尚未加载的默认数据。
- 编辑抽屉直接提供可输入的剩余额度，默认填入当前余额；移除“调整额度”按钮和二次弹窗。点击现有“保存更改”时统一保存，输入或失焦时不写入数据库。
- 只有额度发生变化时才调用 `/api/user/manage`，固定提交 `action: add_quota`、`mode: override`，覆盖余额而非累加或扣减；未修改额度时不覆盖余额。仅修改额度时不调用用户资料更新接口。
- 额度可显式设置为 0；空值、负数、非有限数及换算后超过 JavaScript 安全整数范围的值不能提交。金额沿用系统货币、汇率或 Token 展示配置进行换算。
- 用户资料与额度使用现有两个接口依次保存，并非同一数据库事务。若资料已保存而额度更新失败，提示部分成功并保留额度输入；再次保存只重试尚未保存的变更，不重复提交已保存的密码等信息。
- 额度更新失败时保留输入供重试；取消并重新打开时重新加载当前余额。提交期间禁止重复提交和关闭。
- 用户操作菜单只保留启用/禁用状态切换和删除；移除升降级、绑定管理、订阅管理、重置 Passkey 和重置 2FA 入口。Root 账号仍禁止禁用和删除，删除仍需确认。独立编辑按钮保留。
- 用户列表移除邀请信息和分组列，编辑抽屉移除分组选择。编辑保存时将用户分组设为 `default`；即使其他字段没有变化，也会保存旧用户的非默认分组。额度仍仅在发生变化时覆盖。

## 默认分组与访问配置

所有变更均由前端使用现有接口完成。打开页面或关闭未保存的表单不会修改数据；未编辑的旧记录保留原配置，不执行数据库批量迁移。

| 对象 | 新建或编辑保存时的配置 |
| --- | --- |
| 用户 | 默认分组 `default`；新建沿用后端现有默认分组 |
| API 密钥 | `group: default`，`auto_groups: []`，`cross_group_retry: false`；无 IP、模型白名单，`expired_time: -1` 永不过期 |
| 渠道 | `group: default`，`priority: 0`，`weight: 0`；标签批量编辑同样提交这些值 |
| 订阅方案 | 不再升级用户分组，到期降级目标固定为 `default` |
| 在线试用 | 模型查询和请求固定使用 `default`，忽略历史非默认分组选择 |

- API 密钥列表和表单移除分组、分组倍率、自动分组、跨组重试、IP 白名单、模型白名单和过期时间。名称、额度和创建数量仍可编辑，原有额度不会被此次默认配置转换清空。
- 渠道表格、卡片、编辑抽屉、标签编辑与批量编辑移除分组、优先级和权重入口；同时移除模型预设分组快捷入口。
- 日志筛选与详情、价格列表与详情、个人信息及订阅展示中的用户分组信息一并清理。价格列表使用默认分组，设置导航移除分组计费，限流与渠道亲和性表单移除分组控件。
- 后端分组倍率与权限校验继续使用现有配置。本次隐藏对应页面入口，不会修改后端计费规则、数据库结构或未编辑的历史数据。

本次改动仅涉及前端，未修改后端代码、数据库结构、账号绑定或额度数据。删除入口不等于删除后端功能。
