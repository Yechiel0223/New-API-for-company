# 前端分析页面

- 模型调用分析：`/dashboard/models`，独立一级菜单；保留调用总数、总消费、Token 总量、消费趋势及模型调用趋势/占比/排名，增加用户消费排行与用户消费趋势。
- 用户统计：`/dashboard/users`，进入页面时默认填入当前登录用户名并加载其三项汇总及消费、模型调用图表。点击输入框即展开用户名下拉列表，可直接输入筛选、使用鼠标或方向键与回车选择，再点击“搜索”查询；也可输入完整用户名查询。用户名为空或仅包含空格时提示校验错误，并保留已查询用户的统计。
- 用户名列表复用 `GET /api/user/`，首次展开时按每页 100 条顺序读取至完整列表，按当前登录账号缓存一分钟；查询只缓存用户名。列表加载失败可单独重试，不影响当前用量展示；没有匹配项时显示空结果提示。
- 用户查询复用 `GET /api/data/model-analytics` 的 `username` 参数；时间范围、模型筛选及重置始终保持当前查询用户。切换用户清除旧结果，失败可重试，无记录显示“无调用”。接口不能区分不存在的用户名与没有调用记录的用户。
- RPM、TPM 和性能健康已从分析页面移除，页面不再请求健康接口。
- 用户消费排行与用户消费趋势沿用各自的时间范围、粒度及 Top 用户控制，仅出现在模型调用分析页面。
- 已移除原数据看板菜单及页内双页签，保留旧分析 URL 兼容书签。普通管理员可见模型调用分析、用户统计及用户管理，普通用户不能访问用户统计。
- 已移除使用日志、绘图日志、钱包、个人资料、系统信息的导航入口；钱包、个人资料及系统信息旧地址返回未找到页面，使用日志与绘图日志旧地址均转到任务日志。所有角色仅保留任务日志，头像菜单仅保留账号概要与退出登录。

此次调整仅涉及前端与本说明，后端接口、数据库和账户数据不变。
